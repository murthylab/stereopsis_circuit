# Stereopsis circuit mapping
Code used for "A neural circuit for stereopsis in the fly" ([Mearns et al., 2026](https://www.biorxiv.org/content/10.64898/2026.11.11.765991v1)).

## Connquer
Connquer ("connectome-query") contains code for analyzing connectomic data either using locally saved files downloaded from
[codex](https://codex.flywire.ai/api/download?dataset=fafb) or via [neuprint](https://neuprint.janelia.org/).

## Eye model 3D
3D model of fly ommatidia sightlines, based on microCT data from [Zhao et al. (2025)](https://www.nature.com/articles/s41586-025-09276-5)
and including custom mapping code for visual columns from the connectome.
